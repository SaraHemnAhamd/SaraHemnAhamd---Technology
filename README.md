# SaraHemnAhmad — Tech

A responsive bilingual (Sorani Kurdish / English) personal portfolio website.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Wait for GitHub Pages to publish the site.

## Customize
- Update the biography and interests in `index.html`.
- Add real projects in the Projects section.
- Add GitHub, LinkedIn, or email links in the Contact section.
